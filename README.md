# 👥 Hiring Process Analytics

A data-driven project focused on analyzing hiring data to identify patterns and insights related to **salary, gender distribution, departments, and position tiers**.

The project uses data cleaning, analysis, and visualization to understand different aspects of the hiring process and present meaningful insights from historical hiring data.

## 🎯 Objectives

* Analyze gender distribution in hiring
* Examine salary trends and salary ranges
* Analyze department-wise hiring patterns
* Study position tier distribution
* Identify meaningful patterns and trends in the hiring data
* Present findings through visualizations and reports

## 🛠️ Tools Used

* Microsoft Excel
* MySQL Workbench
* Data Visualization
* Data Cleaning & Analysis
